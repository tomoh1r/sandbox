# sandbox

プログラミング言語・ライブラリ・開発ツールを試すためのサンプル集です。
セットアップ方法や実行手順は、各ディレクトリの README を参照してください。

## サンプル

| ディレクトリ | 内容 |
|---|---|
| [erlang-cluster](erlang-cluster/README.md) | 複数マシンで Erlang ノードを接続し、メッセージ送信・並列計算・切断と再接続を体験。CentOS Stream 9 向けのセットアップ手順と、Podman 用イメージのビルド・実行手順付き。 |
| [github-actions-hello-world](github-actions-hello-world/README.md) | 挨拶をログに出力する JavaScript 製 GitHub Action。 |
| [htmx-flask-quickwin](htmx-flask-quickwin/README.md) | htmx・Flask・SQLite を使った、タスクの追加・完了切り替え・削除ができる Web アプリ。 |
| [javascript-marked](javascript-marked/README.md) | marked を使って Markdown ファイルを読み込み、ブラウザーで表示するサンプル。 |
| [python-pulse](python-pulse/README.md) | Python の asyncio でフォルダーを調べ、ファイル数・容量などを HTML レポートにまとめるツール。 |
